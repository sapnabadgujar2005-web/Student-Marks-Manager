# Student-Marks-Manager
Student Marks Manager is a Simple console-based python application for managing student records and checking their marks. It allow users to add student details ,view student records, and check results through a menu-driven interface.

#Features 
- Add Student details
- view Student records
- check student results
- menu driven console interface
- simple and easy to use

#Technologies used
-Python 3
